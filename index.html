Raycasting Engine in C Demo

Controls

WASD - move camera

left/right arrows - turn camera

up/down arrows - raise/lower camera

E - open doors

spacebar - shoot projectile (feature in the works)

1 - first person view

2 - top-down view

/ - open/close terminal

Commands

Parameters: (required) [optional]

set [variable] [value] - view variables and set values

echo (text) - print text

state - unavailable on the web

run - unavailable on the web

Bugs (not exclusive to the web version)

Door texture rendering

Doors can't be moved through

Features in the works

A dynamic lighting system designed to work with the engine's grid-based map

Sprites existing at different elevation levels, not just the center

Enemies and projectiles

Notes

This version of the engine has been compiled for the web using the SDL3 support of Emscripten.
